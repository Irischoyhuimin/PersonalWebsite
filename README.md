# Iris Choy — Portfolio starter

A responsive, single-page personal portfolio built with plain HTML, CSS, and JavaScript. The visual direction is an original editorial/minimal design inspired by the general feel of modern personal engineering portfolios, not a copy of any one site.

## Preview locally

1. Download and unzip this folder.
2. Open `index.html` in a browser, or use VS Code's Live Server extension.
